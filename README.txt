============================================================
  KMITSURAT ERP Launcher - คู่มือการติดตั้งและใช้งาน
  สำหรับ Windows 10 / Windows 11
============================================================

รายชื่อไฟล์ในชุดนี้
------------------------------------------------------------
  KMITSURAT_ERP_Launcher.bat  - โปรแกรมหลักสำหรับเปิด ERP
  config.ini                  - ไฟล์ตั้งค่า (IP, Port, VPN Name)
  install_shortcut.bat        - ติดตั้ง Shortcut บน Desktop
  icon.ico                    - ไอคอน (ไม่บังคับ, วางไฟล์เองได้)
  README.txt                  - คู่มือนี้


============================================================
ขั้นตอนการติดตั้ง (ทำครั้งแรกครั้งเดียว)
============================================================

ขั้นที่ 1: เตรียมไฟล์
  - วางโฟลเดอร์นี้ไว้ในตำแหน่งที่ต้องการ เช่น
    C:\ERP_Launcher\  หรือ  D:\Tools\ERP_Launcher\
  - ไม่ควรวางใน Desktop โดยตรง (ใช้ Shortcut แทน)
  - ห้ามย้ายไฟล์แยกออกจากกัน ต้องอยู่โฟลเดอร์เดียวกัน

ขั้นที่ 2: ตั้งค่า VPN บน Windows (ถ้าต้องการใช้จากนอก Network)
  - เปิด Windows Settings > Network & Internet > VPN
  - กด "Add a VPN connection"
  - ตั้งชื่อ Connection ให้ตรงกับ VPN_NAME ใน config.ini
    (ค่าเริ่มต้น: KMIT)
  - กรอก Server Address และข้อมูล VPN ตามที่ผู้ดูแลระบบแจ้ง
  - กด Save (ยังไม่ต้องกด Connect)
  หมายเหตุ: ระบบไม่เก็บ Username/Password VPN ในไฟล์ใดๆ
            ผู้ใช้จะต้องกรอกข้อมูลเมื่อ Connect VPN เอง

ขั้นที่ 3: ติดตั้ง Desktop Shortcut
  - ดับเบิลคลิก install_shortcut.bat
  - รอจนกว่าจะแสดงข้อความ "ติดตั้ง Shortcut สำเร็จ"
  - กด Enter เพื่อปิดหน้าต่าง
  - Shortcut "KMITSURAT ERP" จะปรากฏบน Desktop


============================================================
วิธีใช้งานประจำวัน
============================================================

1. ดับเบิลคลิก Shortcut "KMITSURAT ERP" บน Desktop
2. โปรแกรมจะตรวจสอบการเชื่อมต่อ Server อัตโนมัติ

กรณีที่ 1 - อยู่ในวง Network ของมหาวิทยาลัย:
  → เบราว์เซอร์จะเปิด ERP ทันที

กรณีที่ 2 - อยู่นอก Network (ทำงานจากบ้าน หรือ WiFi อื่น):
  → โปรแกรมจะเปิดหน้าตั้งค่า VPN ของ Windows
  → คลิกที่ VPN ชื่อ "KMIT" แล้วกด Connect
  → กรอก Username/Password VPN ของท่าน
  → รอจนสถานะเป็น "Connected"
  → กลับมาที่หน้าต่าง Launcher แล้วกด Enter
  → เบราว์เซอร์จะเปิด ERP


============================================================
การเปลี่ยนค่า Server หรือ VPN (กรณี Server ย้าย)
============================================================

1. เปิดไฟล์ config.ini ด้วย Notepad หรือ Text Editor
2. แก้ไขค่าที่ต้องการ:

   ERP_IP=172.16.1.60     ← เปลี่ยนเป็น IP ใหม่ของ Server
   ERP_PORT=3100          ← เปลี่ยน Port ถ้าจำเป็น
   VPN_NAME=KMIT          ← ต้องตรงกับชื่อ VPN ใน Windows Settings
   ERP_NAME=KMITSURAT ERP ← ชื่อที่แสดงในโปรแกรม

3. บันทึกไฟล์
4. ไม่จำเป็นต้องติดตั้ง Shortcut ใหม่
   (Shortcut เดิมยังใช้ได้ โปรแกรมอ่าน config.ini ทุกครั้งที่เปิด)

หมายเหตุ: ถ้าลบ config.ini โปรแกรมจะสร้างใหม่อัตโนมัติ
          ด้วยค่าเริ่มต้น ERP_IP=172.16.1.60


============================================================
การเพิ่มไอคอนให้ Shortcut
============================================================

1. หาไฟล์ไอคอน .ico ที่ต้องการ
2. เปลี่ยนชื่อเป็น icon.ico
3. วางไว้ในโฟลเดอร์เดียวกับ KMITSURAT_ERP_Launcher.bat
4. รัน install_shortcut.bat อีกครั้งเพื่ออัปเดตไอคอน


============================================================
ข้อกำหนดของระบบ
============================================================

- Windows 10 หรือ Windows 11
- มีเบราว์เซอร์ติดตั้งอยู่ (Chrome, Edge, Firefox ฯลฯ)
- PowerShell (มีติดตั้งมากับ Windows โดยค่าเริ่มต้น)
- ไม่ต้องการสิทธิ์ Administrator สำหรับการใช้งานปกติ

หมายเหตุเรื่องการแสดงผลภาษาไทย:
- ถ้าข้อความไทยแสดงเป็นสัญลักษณ์แปลกๆ ให้ทำดังนี้:
  เปิด Windows Settings > Time & Language > Language & Region
  คลิก "Administrative language settings"
  คลิก "Change system locale..."
  ติ๊ก "Beta: Use Unicode UTF-8 for worldwide language support"
  กด OK แล้ว Restart
  (วิธีนี้ใช้ได้กับ Windows 10 v1903 ขึ้นไป)


============================================================
ปัญหาที่พบบ่อยและวิธีแก้ไข
============================================================

ปัญหา: เปิด Shortcut แล้วหน้าต่างปิดทันที
แก้ไข: ลองดับเบิลคลิก KMITSURAT_ERP_Launcher.bat โดยตรง
       และดูข้อความ Error

ปัญหา: Shortcut สร้างไม่สำเร็จ (PowerShell Error)
แก้ไข: คลิกขวาที่ install_shortcut.bat เลือก
       "Run as administrator" แล้วลองอีกครั้ง

ปัญหา: กด Connect VPN แล้วยังเชื่อมต่อ Server ไม่ได้
แก้ไข: 1. ตรวจสอบว่า VPN สถานะเป็น "Connected" จริงๆ
       2. ตรวจสอบ VPN_NAME ใน config.ini ต้องตรงกับชื่อ
          VPN Connection ใน Windows Settings
       3. ติดต่อผู้ดูแลระบบเพื่อตรวจสอบ VPN Server

ปัญหา: เข้า ERP ได้แต่หน้าเว็บไม่โหลด
แก้ไข: ตรวจสอบ ERP_IP และ ERP_PORT ใน config.ini
       ว่าตรงกับที่ผู้ดูแลระบบแจ้ง


============================================================
ข้อมูลติดต่อ
============================================================

ติดต่อผู้ดูแลระบบ ERP KMITSURAT
เพื่อขอข้อมูล:
  - IP Address / Port ของ Server
  - ข้อมูลการตั้งค่า VPN (Server, Protocol, Username)
